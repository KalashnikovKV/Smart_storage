# Requirements Document — Smart Storage: IT Peripheral Recognition System

## Intent Analysis Summary

- **User Request**: Построить систему компьютерного зрения для распознавания IT-периферии (мышки, зарядки, кабели и т.д.) по цвету и размеру. Система реализует полный пайплайн: image → enhance → segment → clean → detect → decision. Тема: Object Sorting System (Color + Size). Практическое применение: автоматизация приёмки оборудования на склад в IT-отделах.
- **Request Type**: New Project
- **Scope Estimate**: Multiple Components (CV pipeline + GUI + video processing + CSV export)
- **Complexity Estimate**: Moderate (well-defined CV pipeline with multiple stages, standard algorithms)

---

## Functional Requirements

### FR-01: Image Acquisition
- Система должна захватывать изображения с веб-камеры в реальном времени
- Поддержка видеопотока с веб-камеры (покадровая обработка)
- Один предмет на изображении за раз

### FR-02: Image Enhancement (Этап 1 — Enhance)
- Улучшение качества входного изображения перед обработкой
- Коррекция яркости и контраста
- Шумоподавление (denoising)
- Выходной артефакт: улучшенное изображение для визуализации

### FR-03: Image Segmentation (Этап 2 — Segment)
- Сегментация предмета от однотонного фона
- Создание бинарной маски объекта
- Предполагается однотонный фон (белый или чёрный стол/подложка)
- Выходной артефакт: маска сегментации

### FR-04: Mask Cleaning (Этап 3 — Clean)
- Морфологическая очистка маски сегментации
- Удаление шума, заполнение дыр, сглаживание контуров
- Выходной артефакт: очищенная маска

### FR-05: Object Detection and Property Analysis (Этап 4 — Detect)
- Определение bounding box объекта по очищенной маске
- Анализ цвета объекта двумя методами:
  - HSV-анализ (определение доминирующего цвета по диапазонам)
  - K-means кластеризация (автоматическое определение доминирующих цветов)
- Анализ размера объекта (площадь в пикселях, соотношение сторон)
- Возможность сравнения результатов двух методов детекции цвета
- Выходной артефакт: результат детекции (bounding box, цвет, размер)

### FR-06: Decision Making (Этап 5 — Decision)
- Классификация объекта на основе цвета и размера
- Базовый набор категорий (5-7):
  - Мышь (mouse)
  - Клавиатура (keyboard)
  - Зарядка iPhone/Android (charger)
  - Кабель USB-C (usb-c cable)
  - Кабель питания (power cable)
  - Флешка (flash drive)
- Формат решения: текстовый — название категории + уверенность (например: "Зарядка iPhone — 92%")
- Правила классификации на основе комбинации цвет + размер

### FR-07: Visualization and GUI
- Простой GUI (окно приложения) с отображением:
  - Оригинального изображения
  - Улучшенного изображения
  - Маски сегментации
  - Очищенной маски
  - Результата детекции (bounding box)
  - Финального решения (текст категории + уверенность)
- Все 6 этапов пайплайна видны одновременно или последовательно

### FR-08: Video Processing
- Обработка видеопотока с веб-камеры в реальном времени
- Покадровая обработка через полный пайплайн
- Отображение результатов в реальном времени в GUI

### FR-09: Data Export
- Сохранение результатов классификации в CSV/Excel файл
- Поля: timestamp, категория, цвет, размер, уверенность, метод детекции

### FR-10: Pipeline Output Artifacts
- Для каждого обработанного изображения система сохраняет:
  1. Оригинальное изображение
  2. Улучшенное изображение
  3. Маска сегментации
  4. Очищенная маска
  5. Результат детекции (изображение с bounding box)
  6. Финальное решение (текст)

## Non-Functional Requirements

### NFR-01: Technology Stack
- **Язык**: Python 3.10+
- **CV библиотека**: OpenCV (cv2)
- **Научные вычисления**: NumPy, SciPy
- **GUI**: OpenCV highgui или tkinter
- **Экспорт данных**: pandas (для CSV)
- **Кластеризация**: scikit-learn (для K-means)

### NFR-02: Performance
- Обработка одного кадра через полный пайплайн: < 500ms
- Видеопоток: минимум 5-10 FPS для комфортной работы
- Время запуска приложения: < 5 секунд

### NFR-03: Reproducibility
- Чёткие инструкции по установке и запуску
- requirements.txt с зафиксированными версиями зависимостей
- README с описанием установки, запуска и использования
- Примеры тестовых изображений в репозитории

### NFR-04: Code Quality
- Модульная структура (отдельные модули для каждого этапа пайплайна)
- Комментарии в коде на английском языке
- Обработка ошибок (отсутствие камеры, пустое изображение, объект не найден)

### NFR-05: Documentation (Report)
- PDF отчёт 3-5 страниц:
  - Описание проблемы
  - Дизайн пайплайна
  - Используемые методы
  - Результаты с изображениями каждого этапа
  - Случаи неудач (failure cases)
  - Заключение

## Constraints and Assumptions

### Constraints
- Один предмет на изображении за раз
- Однотонный фон (белый или чёрный)
- Базовый набор из 5-7 категорий периферии

### Assumptions
- Веб-камера доступна на устройстве
- Предметы размещаются на контрастном фоне
- Освещение достаточное для корректного определения цвета
- Предметы не перекрывают друг друга (один предмет за раз)
