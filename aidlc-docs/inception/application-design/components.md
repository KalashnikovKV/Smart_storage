# Components — Smart Storage

## Component 1: Pipeline
**Purpose**: Основной класс, реализующий полный CV-пайплайн обработки изображений.
**Responsibilities**:
- Выполнение последовательности этапов: enhance → segment → clean → detect → decide
- Хранение промежуточных результатов каждого этапа
- Предоставление доступа к результатам каждого этапа для визуализации

## Component 2: ColorDetector
**Purpose**: Модуль детекции цвета объекта двумя методами.
**Responsibilities**:
- HSV-анализ: определение доминирующего цвета по HSV-диапазонам
- K-means кластеризация: автоматическое определение доминирующих цветов
- Возврат названия цвета и уверенности для каждого метода

## Component 3: Config
**Purpose**: Модуль конфигурации с правилами классификации и параметрами системы.
**Responsibilities**:
- Хранение правил классификации (цвет + размер → категория) в виде Python-словаря
- Хранение параметров пайплайна (пороги, диапазоны цветов, размеры)
- Хранение категорий периферии и их характеристик

## Component 4: Visualizer
**Purpose**: Модуль визуализации результатов через OpenCV highgui.
**Responsibilities**:
- Отображение оригинального изображения
- Отображение результатов каждого этапа пайплайна (enhance, segment, clean, detect)
- Отображение финального решения (текст категории + уверенность)
- Компоновка всех этапов в единое окно или набор окон

## Component 5: VideoProcessor
**Purpose**: Модуль захвата и обработки видеопотока с веб-камеры.
**Responsibilities**:
- Захват кадров с веб-камеры через OpenCV VideoCapture
- Покадровая передача в Pipeline для обработки
- Управление циклом захвата (старт, стоп, пауза)
- Контроль FPS

## Component 6: DataExporter
**Purpose**: Модуль экспорта результатов классификации в CSV.
**Responsibilities**:
- Формирование записей с полями: timestamp, категория, цвет, размер, уверенность, метод
- Запись результатов в CSV-файл
- Добавление новых записей к существующему файлу

## Component 7: Application (main)
**Purpose**: Точка входа приложения, координация всех компонентов.
**Responsibilities**:
- Инициализация всех компонентов
- Запуск видеопотока или обработка одиночного изображения
- Координация Pipeline → Visualizer → DataExporter
- Обработка пользовательского ввода (клавиши для управления)
